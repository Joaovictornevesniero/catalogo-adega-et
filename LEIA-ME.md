# Catálogo Adega ET Drinks (demo)

HTML, CSS e JS puro, sem build e sem servidor.

## Antes de mostrar ao dono
1. Em `products.js`, troque `whatsapp` pelo número real (55 + DDD + número, só dígitos).
2. Troque os produtos e preços de exemplo pelos reais (peça a lista ao dono).
3. Coloque a logo em `assets/logo.png`.
4. Ajuste `taxaEntrega`, `pedidoMinimo` e `pagamentos`.

## Testar
Abra `index.html` no navegador (duplo clique).

## Publicar de graça (GitHub Pages)
1. Crie um repositório e envie estes arquivos.
2. Settings > Pages > Deploy from a branch > main / root.
3. O link fica `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Para produto esgotado
Em `products.js`, `disponivel: false`.
